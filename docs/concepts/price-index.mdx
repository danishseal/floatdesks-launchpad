Every market carries an on-chain **price index**: the protocol's view of what one whole unit of the synth (1,000,000 tokens) is worth, denominated in **lamports per unit**. The index is **launch-scaled**: at launch, one unit is defined as worth 0.625 SOL, the [launch curve](/concepts/launch-curve)'s migration price, and every push moves it proportionally with the collectible from there:

  <img className="hidden dark:block" src="/images/protocol/11-oracle-pipelines.png" alt="Two estimator pipelines, one launch-scaled index." noZoom />
  <img className="block dark:hidden" src="/images/protocol/11-oracle-pipelines-light.png" alt="Two estimator pipelines, one launch-scaled index." noZoom />
</Frame>

```text
pushed = collectible_price_now / collectible_price_at_launch * 0.625 SOL
```

The index therefore carries the collectible's move since launch rather than its absolute price, which keeps premium, [funding](/concepts/funding), the [breaker](/concepts/circuit-breaker), and CDP math on the same footing for every market, and seeds the AMM at zero premium at [graduation](/concepts/graduation). The index is the reference that everything else keys off: collateral checks, liquidations, and the funding rate that tethers the synth price.

## Push oracle

The index is fed by a push oracle. The market's price feed, a signed relayer service that reads the collectible's real prices from marketplaces and filters manipulation (see [Oracle Architecture](/oracle/architecture)), submits it with the `push_index` instruction, signed by the **oracle authority** key stored in the global config. No other signer can push.

Each push carries a single `price_lamports` value for the whole unit, already launch-scaled by the feed. The first push at launch is `625_000_000` (0.625 SOL); for a collectible that has since doubled, the push is `1_250_000_000`.

Four gates apply before a push is absorbed:

1. **Not frozen**: a frozen market refuses pushes entirely, so the index cannot be walked during a freeze. See [Circuit Breaker](/concepts/circuit-breaker).
2. **Non-zero**: `price_lamports > 0`, otherwise the push is rejected.
3. **Rate limit**: at least `min_push_interval_secs` must have elapsed since the previous push. The first push for a market is exempt.
4. **Circuit breaker**: the push is compared against the current TWAP. If it deviates by more than `breaker_bps`, the market freezes instead of absorbing the value.

## TWAP smoothing

Accepted pushes do not overwrite the index directly. The market stores two values:

- `index_last_raw`: the most recent accepted observation, kept for transparency
- `index_twap`: the smoothed index every risk check actually uses

Smoothing is a time-weighted EMA. Each accepted push pulls the TWAP toward the observation in proportion to how much time has passed, capped at the full window:

```text
w  = index_window_secs
dt = min(seconds since last push, w)

index_twap = (index_twap * (w - dt) + price * dt) / w
```

If the full window has elapsed since the last push, the TWAP lands exactly on the new observation. Rapid-fire pushes move it only fractionally, so no single print can jerk the index.

<Note>
The very first push for a market seeds `index_twap` directly with the observed price. There is no history to average against yet, and most instructions refuse to run until an index exists.
</Note>

## What consumes the index

The index is the valuation leg for every solvency computation. Token amounts are converted to lamport value with:

```text
value = base_units * index_twap / 1_000_000_000_000
```

(1e12 base units per whole unit, see [The Synth Token](/concepts/synth-token).)

| Consumer | How it uses the index |
| --- | --- |
| `open_short` | New debt is valued at the index; collateral must cover `initial_cr_bps` of it |
| `withdraw_collateral` | Remaining collateral is re-checked against debt valued at the index |
| `liquidate` | Positions become liquidatable when collateral falls below `maintenance_cr_bps` of index-valued debt; payouts are index-valued |
| `accrue_funding` | The premium is `(mark_ema - index_twap) / index_twap`; with a launch-scaled index it reads as how the token has done versus the collectible since launch. See [Funding](/concepts/funding) |
| `graduate` | Refuses to run until an index exists |

<Warning>
The AMM's own price (the mark) never enters a collateral or liquidation check. Only the oracle index does. Manipulating the on-chain pool cannot force a liquidation; only the external market price, as reported through the smoothed and breaker-guarded index, can.
</Warning>

## Staleness guard

An index is only as good as its freshness. Every market records `index_last_ts`, the time of the last accepted push, and when `max_index_age_secs` is set (non-zero), index-priced operations refuse to run against an index older than that:

- `open_short`
- `withdraw_collateral` when the position still has debt
- `accrue_funding`
- `liquidate`

A stale market returns `IndexStale` until the next accepted push, at which point everything resumes with no reset needed. Trading (curve and AMM), `repay_burn`, and `add_collateral` stay available throughout, so nobody is trapped: shorts can still de-risk, and holders can still exit through the pool.

This bounds the damage of a dead relayer: prices stop being trusted after the configured age instead of being trusted forever. Set `max_index_age_secs` comfortably above the relayer's push cadence (see [Parameters](/concepts/parameters)); `0` disables the guard, which is only appropriate for testing.

## Instruction and event surface

- Instruction: `push_index(price_lamports)`, oracle authority only, see [Instructions](/reference/instructions)
- Emits `IndexPushed { market, raw, twap }` on absorption, or `BreakerTripped { market, observed, twap }` on a breaker hit, see [Events](/reference/events)
- State fields: `index_twap`, `index_last_raw`, `index_last_ts` on the [Market account](/reference/accounts)

External-venue markets additionally receive an oracle-pushed **mark** price through [`push_mark`](/reference/instructions#push_mark), smoothed the same way over `mark_window_secs`. The mark only steers [funding](/concepts/funding); it never enters collateral or liquidation math, which always use the index documented here.
